# Insurance EDA 📊

An exploratory data analysis project on medical insurance data using Python.

## 📌 About

This project explores the relationship between demographic,
lifestyle, and health-related factors and medical insurance charges.

## 🔍 Analysis

The project explores:

- Age and insurance charges
- BMI and insurance charges
- Smoking status and charges
- Gender differences
- Number of children
- Regional differences
- Relationships between multiple features

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🎯 Purpose

This project was created while learning the fundamentals of
Machine Learning and Exploratory Data Analysis. It helped me
understand data exploration, visualization, feature relationships,
and how data can be analyzed before building an ML model.
